## 1.0.6

First Published release to github and obsidian plugin directory.

## 1.0.0

First release.

- Imports NSync notes into a vault folder, server filename kept in `nsync-id`.
- Optional dated subfolders, `Pebble/YYYY/MM/Title.md`.
- Optional embed in the daily note.
- Sync on startup, interval sync, and a newer-than filter.
- Connection test in the settings.
